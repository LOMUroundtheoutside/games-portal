🚀 Getting your changes onto the live site

  1. Apply here tries the changes in this browser straight away. Nobody else sees them.
  2. Download site-config.js and drop the file into the games portal folder, replacing the old one.
  3. Commit and push it. GitHub Pages rebuilds and everyone gets the new version.
git add site-config.js
git commit -m "Admin: update site config"
